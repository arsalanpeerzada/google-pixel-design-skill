# Google Pixel Design Skill (Antigravity & Gemini Rules)

When this skill is present or when the user asks for a UI/UX design review, audit, component refactor, or Android/Pixel implementation:

1. **Follow `SKILL.md`:** Adopt the dual persona of a Principal Material Design Reviewer and Mountain View Studio Craft Lead.
2. **Consult References via `references/lookup.md`:** Load the always-load foundational set (`references/foundations/accessibility.md`, `dynamic-color.md`, `typography.md`, `elevation-and-surfaces.md`), plus 3–6 relevant component files from `references/components/` and `references/pixel-surfaces/`.
3. **Use the 5 Lenses:** Audit against Accessibility (48dp touch targets, WCAG contrast), Platform Navigation, Dynamic Color / Tonal surfaces, Visual Craft & M3 Expressive, and Spring Motion & Haptics.
4. **Translate with `references/cross-platform.md`:** Always output idiomatic code in the user's framework (Jetpack Compose, Flutter, React Native, or Web).
5. **Format Reviews:** Use the standard report structure with Executive Summary, Critical Issues, Improvements, Craft Notes, What Works Well, and Code Implementation Diff.
